

**Testing the Physics and Observational Validity of White Dwarf Mass–Radius Models**

**中文：**白矮星质量—半径模型的理论构建及观测检验

## 项目想法

我们计划从电子简并压出发，自行建立白矮星结构模型，研究电子从非相对论状态过渡到相对论状态时，白矮星的质量、半径和内部结构如何变化。

在此基础上，我们将使用具有独立质量和半径测量的白矮星观测数据，检验理论模型的适用范围，并分析模型与观测之间的偏差是否与白矮星的质量和温度有关。

项目的核心问题是：

> 电子相对论化如何改变白矮星的质量—半径关系并产生钱德拉塞卡极限？零温理论模型又能在多大程度上解释真实白矮星？

## 研究意义

白矮星由电子简并压支撑，是量子力学、相对论和恒星结构相互联系的典型天体。

基础理论预测低质量白矮星满足近似关系：

[
R\propto M^{-1/3}.
]

但随着中心密度增加，电子动量逐渐接近或超过 (m_ec)，非相对论近似失效。电子简并压对密度的依赖从：

[
P\propto \rho^{5/3}
]

逐渐过渡到：

[
P\propto \rho^{4/3}.
]

这个变化使得继续增加中心密度不再显著增加白矮星总质量，最终产生钱德拉塞卡极限。

真实白矮星也具有有限温度、不同核心成分和非简并表层。因此，我们将进一步研究理想零温模型在哪些条件下有效，以及观测偏差是否显示出系统性规律。

# 第一部分：理论模型

## 1. 电子数密度与质量密度

对于完全电离的白矮星物质，电子数密度可以写为：

[
n_e=\frac{\rho}{\mu_e m_u},
]

其中：

- (\rho) 是物质密度；
- (m_u) 是原子质量单位；
- (\mu_e) 是每个自由电子对应的平均核子数。

氦、碳和氧核心都有近似相同的 (\mu_e=2)。这意味着最简单的理想电子气模型无法有效区分 He、C 和 O 核心，也展示了模型本身的局限。

## 2. Fermi momentum

在零温极限下，电子从低动量状态开始填充，最高被占据的动量为 Fermi momentum：

[
p_F=\hbar(3\pi^2n_e)^{1/3}.
]

定义无量纲相对论参数：

[
x=\frac{p_F}{m_ec}.
]

它可以判断电子处于哪个区域：

- (x\ll1)：非相对论电子；
- (x\sim1)：相对论效应开始重要；
- (x\gg1)：高度相对论电子。

我们将计算中心值 (x_c)，并研究它与白矮星质量、半径及模型误差的关系。

## 3. 三种状态方程

我们将比较三种理论模型。

### Model A：非相对论近似

[
P_{\rm NR}=K_{\rm NR}\rho^{5/3}.
]

该模型适用于较低密度白矮星，并给出近似关系：

[
R\propto M^{-1/3}.
]

但它不会产生有限的钱德拉塞卡质量。

### Model B：高度相对论近似

[
P_{\rm UR}=K_{\rm UR}\rho^{4/3}.
]

这个模型可以解释为什么质量逐渐趋近一个常数，但它不适合描述低密度白矮星的半径。

### Model C：完整零温 Fermi gas

使用电子的相对论能量关系：

[
E^2=p^2c^2+m_e^2c^4
]

计算完整的简并压力：

[
P(x)=
\frac{m_e^4c^5}{8\pi^2\hbar^3}
\left[
x\left(\frac{2x^2}{3}-1\right)\sqrt{1+x^2}
+\sinh^{-1}(x)
\right].
]

完整状态方程能够连续连接非相对论和高度相对论两个极限。

这让我们可以研究：

> 非相对论近似在什么中心密度或 (x_c) 下开始产生明显误差？

## 4. 恒星结构方程

对白矮星采用球对称和 Newtonian gravity：

[
\frac{dm}{dr}=4\pi r^2\rho,
]

[
\frac{dP}{dr}=-\frac{Gm\rho}{r^2}.
]

中心边界条件为：

[
m(0)=0,\qquad \rho(0)=\rho_c.
]

数值积分从接近中心的位置开始，在压力或密度下降到接近零时停止。该位置定义为白矮星表面，得到总半径 (R) 和总质量 (M)。

通过扫描不同中心密度，可以建立：

[
M(\rho_c),\qquad R(\rho_c),\qquad M(R).
]

这个项目会用到相对论性电子状态方程，但引力部分仍是 Newtonian，因此不需要广义相对论或 TOV 方程。

## 5. 理论研究问题

理论部分不只计算一条质量—半径曲线，而是回答：

1. 非相对论模型与完整模型在什么密度下相差超过 1%、5% 和 10%？
2. 半径和质量中，哪一个更早显示出相对论修正？
3. (x_c\sim1) 是否对应明显的模型偏离？
4. 随着 (\rho_c) 增加，为什么质量逐渐趋于极限，而半径继续减小？
5. 数值积分步长对极限质量有多大影响？
6. 改变 (\mu_e) 时，极限质量是否满足：

[
M_{\rm Ch}\propto\mu_e^{-2}?
]

这些问题使理论部分成为一个数值实验，而不只是复现教科书中的最终数值。

# 第二部分：观测检验

## 1. 数据来源

我们计划使用掩食双星系统中的白矮星数据。这类系统可以通过掩食光变和轨道运动测量白矮星的质量与半径，对理论质量—半径关系的依赖较少。

主要样本可以使用 Parsons et al. (2017) 汇总的数据。所需变量包括：

- 观测质量 (M_{\rm obs})；
- 质量误差 (\sigma_M)；
- 观测半径 (R_{\rm obs})；
- 半径误差 (\sigma_R)；
- 有效温度 (T_{\rm eff})；
- 天体名称。

我们不直接使用由理论质量—半径关系推导出的 catalog mass，以避免使用理论产生的数据反过来验证同一个理论。

## 2. 理论预测与观测比较

对于每颗白矮星，根据观测质量从理论曲线上插值得到：

[
R_{\rm cold}(M_{\rm obs}).
]

定义相对半径残差：

[
\delta R=
\frac{R_{\rm obs}-R_{\rm cold}}
{R_{\rm cold}}.
]

同时考虑质量和半径误差，计算标准化残差：

[
z=
\frac{R_{\rm obs}-R_{\rm cold}}
{\sqrt{
\sigma_R^2+
\left(\frac{dR}{dM}\sigma_M\right)^2
}}.
]

这样可以判断某个偏差是否大于观测不确定度。

## 3. 温度与质量趋势

我们将检验：

[
\delta R \quad \text{与}\quad T_{\rm eff}
]

以及：

[
\delta R \quad \text{与}\quad M
]

是否存在相关性。

可能采用：

- Spearman 相关系数；
- 加权线性拟合；
- bootstrap 置信区间；
- 冷、热白矮星分组比较；
- 低质量与普通质量白矮星分组比较。

较热白矮星可能因为有限温度效应而具有较大的半径，但这将作为待检验假设，而不是预设结论。

## 4. 可选的有限温度模型

如果时间允许，可以使用公开的 Montréal 白矮星冷却模型，根据每颗星的质量和有效温度取得：

[
R_{\rm finite-T}(M,T_{\rm eff}).
]

然后比较：

- 我们的零温模型；
- 公开的有限温度模型；
- 实际观测结果。

研究加入有限温度后，预测误差是否减小。

# 第三部分：动画与可视化

动画将包含三个同步区域。

## 左侧：内部结构

显示：

[
\rho(r)/\rho_c
]

随中心密度变化的过程，观察半径收缩和中心集中程度增加。

## 中间：质量—半径关系

同时显示：

- 非相对论模型；
- 完整零温 Fermi gas 模型；
- 当前中心密度对应的模型点；
- 钱德拉塞卡极限；
- 带误差棒的观测点。

## 右侧：相对论程度与模型误差

显示：

- 中心相对论参数 (x_c)；
- 非相对论模型与完整模型的半径差异；
- 当前模型与观测数据的残差。

动画进度轴使用：

[
\log_{10}\rho_c,
]

而不是时间，因为每一帧代表不同中心密度下的平衡模型。

# 衡量指标

项目将使用以下指标：

| 指标                         | 研究目的                       |
| ---------------------------- | ------------------------------ |
| 非相对论与完整模型的半径差   | 确定非相对论近似何时失效       |
| 非相对论与完整模型的质量差   | 衡量相对论效应                 |
| (x_c)                        | 描述中心电子的相对论程度       |
| (M_{\rm Ch})                 | 测量理论极限质量               |
| 数值收敛误差                 | 验证积分结果是否可靠           |
| 观测半径相对残差             | 衡量模型预测准确度             |
| 标准化残差                   | 判断偏差是否超过观测误差       |
| Reduced (\chi^2)             | 比较整体模型表现               |
| 残差与温度的相关性           | 检验有限温度影响               |
| 冷模型与有限温度模型误差差异 | 判断增加物理复杂度是否改善结果 |

# 工作比例

调整后的建议比例为：

- **理论与数值模拟：55%**
- **观测数据与统计分析：45%**

理论部分的重点是比较三种状态方程、确定近似失效的位置，并解释钱德拉塞卡极限如何从电子相对论化中产生。观测部分负责检验这一理想模型在真实白矮星中的适用范围。

# 最低可行版本

必须完成：

1. 非相对论与完整零温状态方程；
2. Newtonian 恒星结构方程的数值积分；
3. 质量—半径曲线和钱德拉塞卡极限；
4. 非相对论近似的误差分析；
5. 数值收敛测试；
6. 掩食双星观测数据比较；
7. 残差与温度或质量的关系；
8. 展示内部结构和质量—半径曲线的动画。

如果时间允许，再加入有限温度模型。

# 预期结论

项目最终希望回答两个相互联系的问题：

1. 电子从非相对论状态转向相对论状态时，白矮星结构如何变化，并最终产生质量上限？
2. 这个理想零温模型能在多大程度上解释真实白矮星，模型偏差又是否与温度和质量有关？

这样，钱德拉塞卡极限不再只是需要复现的教科书答案，而成为一个可以通过数值模拟理解、并通过真实观测数据检验的理论预测。
